## 5. 常见问题排查
| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 日志无 `[YueyuKeyboard] 已加载` | deb 未安装/注入过滤不对 | 检查 `layout/.../YueyuKeyboard.plist` 的 Bundles 是否为 com.tencent.mqq；重装并重启 |
| 命令式不生效 | hook 的类/方法在设备上不同 | `search_header.ps1` 复查，改用日志确认 `actionSend` 是否被调用 |
| 按钮不出现 | QQ 新版未用 `QQInputAccessoryView` | 换 hook `QQInputTextView`/`QQMinAIOInputbar`，或改挂 keyWindow 浮动按钮 |
| 翻译失败弹窗 | 断网 / 端点被墙 | 日志看 error；考虑换百度/有道/DeepL（YueyuTranslator 里替换端点） |
| 按钮挡到 QQ 图标 | 布局冲突 | 调整 trailing 常量 / 改小宽度，或改为命令式 |
| 卸载后仍有残留 | 缓存 | 重启 QQ，必要时 `dpkg --purge com.yueyu.qqkeyboard` |
